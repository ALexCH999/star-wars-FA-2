# Star Wars — Веб-приложение для управления персонажами

Веб-приложение на **FastAPI** для управления фракциями и персонажами из вселенной Star Wars с административной панелью, системой пользователей и защитой от основных типов кибератак.

## 🎯 Функциональность

- **Публичная часть:**
  - Просмотр фракций и персонажей
  - Регистрация и авторизация пользователей
  - Отправка предложений и обращений администратору

- **Административная панель:**
  - Управление фракциями (добавление, редактирование, удаление)
  - Управление персонажами (добавление, редактирование, удаление)
  - Просмотр и обработка обращений пользователей
  - Загрузка изображений (JPG, PNG, GIF, WEBP)

## 🛠️ Технологический стек

| Компонент        | Технология                                     |
| ---------------- | ---------------------------------------------- |
| **Backend**      | Python 3.10+ с FastAPI                         |
| **БД**           | PostgreSQL с SQLModel ORM                      |
| **Фронтенд**     | HTML/CSS/JavaScript (Jinja2 шаблоны)           |
| **Стили**        | Bootstrap 5 + CSS                              |
| **Безопасность** | Scrypt хеширование, CSRF токены, HttpOnly куки |

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- PostgreSQL 15+

### Установка

```bash
# 1. Клонируем репозиторий
git clone <repo-url>
cd star-wars-FA-2

# 2. Создаём виртуальное окружение
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# 3. Устанавливаем зависимости
pip install -r requirements.txt

# 4. Настраиваем переменные окружения
# Копируем .env.example в .env и заполняем:
cp .env.example .env
# Затем отредактируйте .env с вашими значениями

# 5. Запускаем сервер
uvicorn main:app --reload
```

Приложение будет доступно по адресу: **http://localhost:8000**

## 🔒 Безопасность

Приложение защищено от основных типов кибератак:

| Уязвимость                            | Защита                                               |
| ------------------------------------- | ---------------------------------------------------- |
| **SQL Injection**                     | Параметризованные запросы через SQLModel             |
| **XSS (Cross-Site Scripting)**        | Автоматическое экранирование в Jinja2                |
| **CSRF (Cross-Site Request Forgery)** | CSRF токены на каждой форме                          |
| **Brute Force атаки**                 | Rate limiting (максимум 5 попыток входа за 15 минут) |
| **Слабые пароли**                     | Использование Scrypt (медленное хеширование)         |
| **Перехват куки**                     | HttpOnly и SameSite флаги                            |

## 📝 API Endpoints

### Публичные

- `GET /` — Главная страница
- `GET /faction/{id}` — Просмотр фракции и её персонажей
- `GET /hero/{id}` — Просмотр персонажа
- `POST /register` — Регистрация пользователя
- `POST /login` — Вход пользователя

### Защищённые (требуют авторизации)

- `POST /suggestions` — Отправить обращение
- `GET /suggestions` — Просмотр обращений

### Административные (требуют пароля админа)

- `POST /admin/add-faction` — Добавить фракцию
- `POST /admin/edit-faction/{id}` — Редактировать фракцию
- `POST /admin/add-hero` — Добавить персонажа
- `POST /admin/edit-hero/{id}` — Редактировать персонажа
- `POST /admin/delete-faction/{id}` — Удалить фракцию
- `POST /admin/delete-hero/{id}` — Удалить персонажа
